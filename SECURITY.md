# Security

Please report security issues privately by email to **contact@hopvote.com**, not in public issues or pull requests.

Include what you found, how to reproduce it, and what it affects. We will answer, fix what needs fixing, and tell you when it is done.

This covers the code in this repository and the hosted service at hopvote.com. Please do not test against other people's accounts or data, and do not run load tests against hopvote.com.
